# Serial illustration plates

These 22 portrait plates are the visual layer for the iNQ comic-size serial edition. They use one consistent Q model: a tall, slender, worn silver humanoid robot with an expressive nonhuman face and a question-mark chest emblem.

The plates are intentionally generated without readable lettering, logos, or watermarks. Episode titles are typeset in the serial PDFs so the illustrations remain reusable for print and screen layouts.

See [`../serial/README.md`](../serial/README.md) for the episode index and the Spanish and English serial PDFs.
